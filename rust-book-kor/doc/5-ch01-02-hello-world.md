프로젝트 디렉토리 설정
먼저 Rust 코드를 저장할 디렉토리를 생성해야 합니다. Rust는 코드의 위치를 ​​중요하게 생각하지 않지만, 이 책의 연습 문제와 프로젝트를 위해서는 홈 디렉토리에 `projects` 디렉토리를 만들고 모든 프로젝트를 그 안에 저장하는 것을 권장합니다.

터미널을 열고 다음 명령어를 입력하여 projects 디렉토리를 생성하고, projects 디렉토리 안에 “Hello, world!” 프로젝트 디렉토리를 생성하세요 .

Linux, macOS 및 Windows의 PowerShell에서는 다음을 입력하십시오.

$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world
Windows 명령 프롬프트(CMD)에서는 다음을 입력하십시오.

> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world

Rust 프로그램 기초
다음으로, main.rs 라는 새 소스 파일을 만드세요 . Rust 파일은 항상 .rs 확장자로 끝납니다. 파일 이름에 두 개 이상의 단어를 사용하는 경우, 밑줄(_)로 구분하는 것이 관례입니다. 예를 들어 helloworld.rs 대신 hello_world.rs를 사용하세요 .

이제 방금 생성한 main.rs 파일을 열고 목록 1-1의 코드를 입력하십시오.

파일명: main.rs
fn main() {
    println!("Hello, world!");
}
목록 1-1 : 출력하는 프로그램Hello, world!
파일을 저장하고 ~/projects/hello_world 디렉토리 의 터미널 창으로 돌아갑니다 . Linux 또는 macOS에서는 다음 명령어를 입력하여 파일을 컴파일하고 실행합니다.

$ rustc main.rs
$ ./main
Hello, world!
.\mainWindows에서는 다음 명령어를 입력하세요 ./main:

> rustc main.rs
> .\main
Hello, world!
운영 체제와 관계없이 해당 문자열이 Hello, world!터미널에 출력되어야 합니다. 만약 이 출력이 표시되지 않으면 설치 섹션의 "문제 해결" 부분을 참조하여 도움을 받으세요.

만약 Hello, world!출력이 되었다면, 축하합니다! 당신은 공식적으로 Rust 프로그램을 작성했습니다. 이제 당신은 Rust 프로그래머입니다. 환영합니다!


Rust 프로그램의 구조
이 "Hello, world!" 프로그램을 자세히 살펴보겠습니다. 퍼즐의 첫 번째 조각은 다음과 같습니다.

fn main() {

}
이 줄들은 라는 이름의 함수를 정의합니다 main. 이 main함수는 특별한데, 모든 실행 가능한 Rust 프로그램에서 항상 가장 먼저 실행되는 코드이기 때문입니다. 여기서 첫 번째 줄은 main매개변수가 없고 아무것도 반환하지 않는 라는 이름의 함수를 선언합니다. 만약 매개변수가 있다면 괄호 ( ()) 안에 넣어야 합니다.

함수 본문은 중괄호로 감싸져 있습니다 {}. Rust에서는 모든 함수 본문을 중괄호로 묶어야 합니다. 함수 선언과 같은 줄에 여는 중괄호를 쓰고 그 사이에 공백 하나를 넣는 것이 좋은 스타일입니다.

참고: Rust 프로젝트 전체에서 표준 스타일을 유지하려면 rustfmt특정 스타일로 코드를 포맷하는 자동 포맷터 도구를 사용할 수 있습니다(자세한 내용은 부록 D 참조rustfmt ) . Rust 팀은 이 도구를 표준 Rust 배포판에 그대로 포함시켰으므로 이미 컴퓨터에 설치되어 있을 것입니다!rustc

함수 의 본문에는 main다음 코드가 포함되어 있습니다.

println!("Hello, world!");
이 작은 프로그램에서 모든 작업을 수행하는 것은 바로 이 한 줄입니다. 화면에 텍스트를 출력하는 것이죠. 여기서 주목해야 할 중요한 세부 사항이 세 가지 있습니다.

먼저, println!`Rust 매크로`는 Rust 매크로를 호출합니다. 만약 함수를 호출했다면 ` Rust 매크로 println` (괄호 `--` 없이 )와 같이 입력했을 것입니다. Rust 매크로는 Rust 구문을 확장하는 코드를 생성하는 코드를 작성하는 방법이며, 20장! 에서 더 자세히 다룰 것입니다 . 지금은 `--`를 사용하는 것은 일반 함수 대신 매크로를 호출하는 것이며, 매크로는 함수와 항상 동일한 규칙을 따르지는 않는다는 것만 알아두면 됩니다 .!

둘째, 문자열이 보입니다 "Hello, world!". 이 문자열을 인수로 전달하면 println!화면에 출력됩니다.

세 번째로, 세미콜론( ;)으로 줄을 끝맺습니다. 이는 해당 표현식이 끝났고 다음 표현식이 시작될 준비가 되었음을 나타냅니다. Rust 코드의 대부분은 세미콜론으로 끝납니다.


컴파일 및 실행
방금 새로 만든 프로그램을 실행했으니, 그 과정의 각 단계를 살펴보겠습니다.

rustcRust 프로그램을 실행하기 전에, 다음과 같이 소스 파일 이름을 전달하는 명령어를 입력하여 Rust 컴파일러로 컴파일해야 합니다 .

$ rustc main.rs
C나 C++ 경험이 있다면, 이것이 gcc 또는 와 유사하다는 것을 알 수 있을 것입니다 clang. 컴파일이 성공적으로 완료되면 Rust는 실행 가능한 바이너리 파일을 출력합니다.

lsLinux, macOS 및 Windows의 PowerShell에서는 셸에 다음 명령어 를 입력하여 실행 파일을 확인할 수 있습니다 .

$ ls
main  main.rs
Linux 및 macOS에서는 두 개의 파일이 표시됩니다. Windows의 PowerShell에서는 CMD를 사용할 때와 마찬가지로 세 개의 파일이 표시됩니다. Windows의 CMD에서 다음 명령어를 입력합니다.

> dir /B %= the /B option says to only show the file names =%
main.exe
main.pdb
main.rs
여기에는 .rs 확장자를 가진 소스 코드 파일 , 실행 파일( Windows에서는 main.exe , 다른 모든 플랫폼에서는 main ), 그리고 Windows를 사용하는 경우 .pdb 확장자를 가진 디버깅 정보 파일이 표시됩니다. 여기에서 다음과 같이 main 또는 main.exe 파일을 실행합니다 .

$ ./main # or .\main on Windows
main.rs 파일이 "Hello, world!" 프로그램 이라면 , 이 줄이 Hello, world!터미널에 출력됩니다.

Ruby, Python, JavaScript와 같은 동적 언어에 익숙하다면 프로그램을 컴파일하고 실행하는 단계를 따로 두는 것이 어색하게 느껴질 수 있습니다. Rust는 사전 컴파일 언어이기 때문에 프로그램을 컴파일하여 실행 파일을 다른 사람에게 제공하면 Rust가 설치되어 있지 않아도 실행할 수 있습니다. .rb , .py , .js 파일을 다른 사람에게 제공하면 각각 Ruby, Python, JavaScript를 설치해야 합니다. 하지만 이러한 언어에서는 컴파일과 실행에 단 하나의 명령어만 필요합니다. 언어 설계에는 항상 장단점이 존재합니다.

간단한 프로그램의 경우 컴파일만으로 rustc충분하지만, 프로젝트 규모가 커질수록 모든 옵션을 관리하고 코드를 쉽게 공유하고 싶어질 것입니다. 다음으로는 실제 Rust 프로그램을 작성하는 데 도움이 되는 Cargo 도구를 소개하겠습니다.
