Rust 프로그래밍 언어 입문서인 『 Rust 프로그래밍 언어』 에 오신 것을 환영합니다 . Rust 프로그래밍 언어는 더 빠르고 안정적인 소프트웨어를 작성하는 데 도움을 줍니다. 프로그래밍 언어 설계에서 고수준의 편의성과 저수준의 제어는 종종 상충되지만, Rust는 이러한 갈등에 도전합니다. 강력한 기술적 역량과 뛰어난 개발자 경험의 균형을 통해 Rust는 기존 방식에서 흔히 발생했던 번거로움 없이 메모리 사용량과 같은 저수준 세부 사항을 제어할 수 있는 옵션을 제공합니다.

Rust는 누구를 위한 제품인가요?
Rust는 다양한 이유로 많은 사람들에게 이상적인 플랫폼입니다. 그중 가장 중요한 몇 가지 그룹을 살펴보겠습니다.

개발자 팀
Rust는 시스템 프로그래밍 지식 수준이 다양한 대규모 개발자 팀 간의 협업에 매우 효과적인 도구임이 입증되고 있습니다. 저수준 코드는 다양한 미묘한 버그에 취약한데, 대부분의 다른 언어에서는 숙련된 개발자의 광범위한 테스트와 꼼꼼한 코드 리뷰를 통해서만 이러한 버그를 발견할 수 있습니다. Rust에서는 컴파일러가 게이트키퍼 역할을 하여 동시성 버그를 포함한 이러한 찾기 어려운 버그가 있는 코드를 컴파일하지 않도록 합니다. 컴파일러와 함께 작업함으로써 팀은 버그를 추적하는 데 시간을 낭비하는 대신 프로그램의 논리 설계에 집중할 수 있습니다.

Rust는 또한 최신 개발자 도구를 시스템 프로그래밍 분야에 제공합니다.

포함된 의존성 관리자 및 빌드 도구인 Cargo를 사용하면 Rust 생태계 전반에서 의존성을 추가, 컴파일 및 관리하는 것이 간편하고 일관성 있게 이루어집니다.
서식 rustfmt지정 도구는 개발자 간에 일관된 코딩 스타일을 보장합니다.
Rust 언어 서버는 코드 자동 완성 및 인라인 오류 메시지를 위한 통합 개발 환경(IDE) 통합을 지원합니다.
러스트 생태계의 이러한 도구들을 비롯한 다양한 도구를 활용하면 개발자는 시스템 수준 코드를 작성하는 동안 생산성을 높일 수 있습니다.

재학생
Rust는 학생들과 시스템 개념 학습에 관심 있는 사람들을 위한 언어입니다. 많은 사람들이 Rust를 사용하여 운영체제 개발과 같은 주제를 배우고 있습니다. Rust 커뮤니티는 매우 개방적이며 학생들의 질문에 기꺼이 답변해 줍니다. Rust 팀은 이 책과 같은 노력을 통해, 특히 프로그래밍 초보자들을 포함하여 더 많은 사람들이 시스템 개념을 쉽게 접할 수 있도록 하고자 합니다.

회사들
수백 개의 대기업과 중소기업이 명령줄 도구, 웹 서비스, DevOps 도구, 임베디드 장치, 오디오 및 비디오 분석 및 트랜스코딩, 암호화폐, 생물정보학, 검색 엔진, 사물 인터넷 애플리케이션, 머신 러닝, 심지어 Firefox 웹 브라우저의 주요 부분에 이르기까지 다양한 작업에 Rust를 실제 운영 환경에서 사용하고 있습니다.

오픈 소스 개발자
Rust는 Rust 프로그래밍 언어, 커뮤니티, 개발자 도구 및 라이브러리를 구축하고자 하는 사람들을 위한 것입니다. Rust 언어에 기여해 주시면 정말 감사하겠습니다.

속도와 안정성을 중시하는 사람들
Rust는 속도와 안정성을 모두 중시하는 사람들을 위한 언어입니다. 여기서 속도란 Rust 코드가 실행되는 속도뿐 아니라 Rust를 사용하면 프로그램을 작성하는 속도까지 모두 포함합니다. Rust 컴파일러의 검사 기능은 기능 추가 및 리팩토링을 통해 안정성을 보장합니다. 이는 이러한 검사 기능이 없는 언어에서 발생하는 취약한 레거시 코드와는 대조적입니다. 개발자들은 이러한 레거시 코드를 수정하는 것을 꺼리는 경우가 많습니다. Rust는 제로 코스트 추상화, 즉 수동으로 작성한 코드만큼 빠르게 하위 레벨 코드로 컴파일되는 상위 레벨 기능을 추구함으로써 안전한 코드가 빠른 코드가 되도록 노력합니다.

Rust 언어는 여기에 언급된 사용자들을 포함하여 훨씬 더 많은 사용자를 지원하고자 합니다. Rust의 궁극적인 목표는 안전성 과 생산성, 속도 와 사용 편의성을 제공함으로써 프로그래머들이 수십 년 동안 감수해 온 절충점을 없애는 것입니다. Rust를 직접 사용해보고 자신에게 맞는 선택인지 확인해 보세요.

이 책은 누구를 위한 책인가요?
이 책은 독자가 다른 프로그래밍 언어로 코드를 작성해 본 경험이 있다고 가정하지만, 어떤 언어인지에 대해서는 아무런 가정도 하지 않습니다. 다양한 프로그래밍 배경을 가진 사람들이 쉽게 이해할 수 있도록 내용을 구성하려고 노력했습니다. 프로그래밍이란 무엇 인지 , 어떻게 생각해야 하는지에 대한 설명은 최소화했습니다. 프로그래밍을 전혀 접해보지 못한 분이라면 프로그래밍 입문서를 읽는 것이 더 도움이 될 것입니다.

이 책을 사용하는 방법
이 책은 일반적으로 독자가 앞에서부터 뒤로 순서대로 읽는 것을 전제로 합니다. 뒷부분의 장들은 앞부분의 장에서 다룬 개념을 바탕으로 하고, 앞부분의 장들은 특정 주제에 대해 자세히 다루지는 않지만 뒷부분의 장에서 다시 언급될 수 있습니다.

이 책에는 개념 장과 프로젝트 장, 이렇게 두 종류의 장이 있습니다. 개념 장에서는 Rust의 특정 측면에 대해 배우고, 프로젝트 장에서는 지금까지 배운 내용을 적용하여 간단한 프로그램을 함께 만들어 봅니다. 2장, 12장, 21장은 프로젝트 장이고, 나머지는 개념 장입니다.

1장에서는 Rust 설치 방법, "Hello, world!" 프로그램 작성 방법, 그리고 Rust의 패키지 관리자이자 빌드 도구인 Cargo 사용법을 설명합니다. 2장 에서는 Rust로 프로그램을 작성하는 실습을 통해 숫자 추측 게임을 만들어 봅니다. 2장에서는 기본적인 개념을 개괄적으로 다루고, 이후 장에서 더 자세한 내용을 설명합니다. 바로 실습을 시작하고 싶다면 2장을 참고하세요. 하지만 모든 내용을 꼼꼼히 배우고 다음 단계로 넘어가는 것을 선호하는 학습자라면 2장을 건너뛰고 다른 프로그래밍 언어와 유사한 Rust 기능들을 다루는 3장 으로 바로 넘어가는 것이 좋습니다 . 3장에서 배운 내용을 적용하는 프로젝트를 진행하고 싶을 때 2장으로 돌아가면 됩니다.

4장 에서는 Rust의 소유권 시스템에 대해 알아봅니다. 5장 에서는 구조체와 메서드에 대해 다룹니다. 6장에서는 열거형, match표현식, 그리고 if let제어 let...else흐름 구조를 다룹니다. 구조체와 열거형을 사용하여 사용자 정의 타입을 만들게 됩니다.

7장 에서는 Rust의 모듈 시스템과 코드 구성을 위한 개인정보 보호 규칙, 그리고 공개 애플리케이션 프로그래밍 인터페이스(API)에 대해 알아봅니다. 8장에서는 표준 라이브러리에서 제공하는 일반적인 컬렉션 데이터 구조인 벡터, 문자열, 해시맵에 대해 설명합니다. 9장에서는 Rust의 오류 처리 철학과 기법을 살펴봅니다.

10장에서는 제네릭, 트레이트, 라이프타임에 대해 자세히 살펴봅니다. 이러한 개념들을 활용하면 여러 타입에 적용되는 코드를 정의할 수 있습니다. 11장에서는 테스트에 대해 다룹니다. Rust의 안전성 보장에도 불구하고 프로그램 로직의 정확성을 확인하기 위해서는 테스트가 필수적입니다. 12장 에서는 명령줄 도구 에서 파일 내 텍스트를 검색하는 기능을 구현해 봅니다 grep. 이를 위해 이전 장에서 다룬 여러 개념들을 활용할 것입니다.

13장 에서는 함수형 프로그래밍 언어에서 유래한 Rust의 특징인 클로저와 이터레이터를 살펴봅니다. 14장 에서는 Cargo를 더 자세히 알아보고 라이브러리를 다른 사람과 공유하는 모범 사례에 대해 논의합니다. 15장에서는 표준 라이브러리에서 제공하는 스마트 포인터와 해당 기능을 구현하는 트레이트에 대해 설명합니다.

16장 에서는 다양한 동시 프로그래밍 모델을 살펴보고 Rust가 어떻게 멀티 스레드 프로그래밍을 안전하게 지원하는지 알아보겠습니다. 17장 에서는 Rust의 async 및 await 구문과 태스크, 퓨처, 스트림, 그리고 이러한 요소들이 가능하게 하는 경량 동시성 모델을 자세히 살펴봅니다.

18장에서는 Rust 관용구와 여러분이 익숙한 객체 지향 프로그래밍 원칙을 비교해 봅니다. 19장 에서는 Rust 프로그램 전반에 걸쳐 아이디어를 표현하는 강력한 방법인 패턴과 패턴 매칭에 대한 참고 자료를 제공합니다. 20장에서는 안전하지 않은 Rust 코드, 매크로, 그리고 수명, 특성, 타입, 함수, 클로저 등 다양한 고급 주제를 다룹니다.

21장 에서는 저수준 멀티스레드 웹 서버를 구현하는 프로젝트를 완료할 것입니다!

Rust를 배우는 과정에서 중요한 부분은 컴파일러가 표시하는 오류 메시지를 읽는 방법을 배우는 것입니다. 이러한 오류 메시지는 올바른 코드를 작성하는 데 도움이 됩니다. 따라서 컴파일되지 않는 예제와 각 상황에서 컴파일러가 보여주는 오류 메시지를 많이 제공할 것입니다. 임의의 예제를 입력하고 실행하면 컴파일되지 않을 수 있다는 점을 기억하세요! 실행하려는 예제가 오류를 발생시키도록 의도된 것인지 확인하려면 주변 텍스트를 읽어보세요. 대부분의 경우 컴파일되지 않는 코드에 대해서도 올바른 버전을 안내해 드릴 것입니다. 또한 Ferris는 의도적으로 작동하지 않도록 만들어진 코드를 구별하는 데 도움을 줄 것입니다.
