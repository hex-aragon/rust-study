설치
첫 번째 단계는 Rust를 설치하는 것입니다. Rust 버전 및 관련 도구를 관리하는 명령줄 도구인 `npm install rust`를 통해 Rust를 다운로드할 것입니다 rustup. 다운로드를 위해서는 인터넷 연결이 필요합니다.

rustup참고: 어떤 이유로든 이 방법을 사용하고 싶지 않으시면 , 다른 Rust 설치 방법 페이지를 참조하여 다른 옵션을 확인하십시오.

다음 단계는 최신 안정 버전의 Rust 컴파일러를 설치하는 방법입니다. Rust의 안정성 보장 덕분에 이 책에 있는 모든 예제는 컴파일이 완료되면 새로운 Rust 버전에서도 계속해서 컴파일됩니다. Rust는 오류 메시지와 경고를 개선하는 경우가 많기 때문에 버전에 따라 출력 결과가 약간 다를 수 있습니다. 즉, 이 단계를 따라 설치하는 최신 안정 버전의 Rust는 이 책의 내용을 문제없이 실행할 수 있도록 해줍니다.

명령줄 표기법
이 장과 책 전체에 걸쳐 터미널에서 사용되는 몇 가지 명령어를 보여드리겠습니다. 터미널에 입력해야 하는 모든 줄은 로 시작합니다 $. 문자 는 입력할 필요가 없습니다. $각 명령어의 시작을 나타내는 명령 프롬프트입니다. 로 시작하지 않는 줄은 $일반적으로 이전 명령어의 출력을 보여줍니다. 또한 PowerShell 관련 예제에서는 >대신 를 사용합니다 $.

rustupLinux 또는 macOS에 설치하기
리눅스 또는 macOS를 사용 중이라면 터미널을 열고 다음 명령어를 입력하세요.

$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
rustup 이 명령어를 실행하면 스크립트가 다운로드되고, 최신 안정 버전의 Rust를 설치하는 도구 설치가 시작됩니다 . 암호를 입력하라는 메시지가 나타날 수 있습니다. 설치가 성공적으로 완료되면 다음 줄이 표시됩니다.

Rust is installed now. Great!
Rust를 사용하려면 컴파일된 출력 파일을 하나의 파일로 합치는 데 사용하는 링커 프로그램 도 필요합니다 . 아마 이미 설치되어 있을 것입니다. 링커 오류가 발생하면 C 컴파일러를 설치해야 합니다. C 컴파일러에는 일반적으로 링커가 포함되어 있습니다. AC 컴파일러도 유용합니다. 일부 일반적인 Rust 패키지는 C 코드에 의존하므로 C 컴파일러가 필요하기 때문입니다.

macOS에서는 다음 명령을 실행하여 C 컴파일러를 얻을 수 있습니다.

$ xcode-select --install
리눅스 사용자라면 일반적으로 사용하는 배포판의 설명서에 따라 GCC 또는 Clang을 설치해야 합니다. 예를 들어, 우분투를 사용하는 경우 해당 build-essential패키지를 설치할 수 있습니다.

rustupWindows에 설치하기
Windows에서는 https://www.rust-lang.org/tools/install 로 이동하여 Rust 설치 지침을 따르세요. 설치 과정 중 Visual Studio를 설치하라는 메시지가 나타날 수 있습니다. Visual Studio는 프로그램 컴파일에 필요한 링커와 네이티브 라이브러리를 제공합니다. 이 단계에 대한 자세한 도움이 필요하면 https://rust-lang.github.io/rustup/installation/windows-msvc.html 을 참조하세요 .

이 책의 나머지 부분에서는 cmd.exe 와 PowerShell 모두에서 작동하는 명령어를 사용합니다. 특정 차이점이 있는 경우 어떤 명령어를 사용해야 하는지 설명하겠습니다.

문제 해결
Rust가 제대로 설치되었는지 확인하려면 셸을 열고 다음 명령어를 입력하세요.

$ rustc --version
다음 형식으로 최신 안정 버전의 버전 번호, 커밋 해시 및 커밋 날짜를 확인할 수 있습니다.

rustc x.y.z (abcabcabc yyyy-mm-dd)
이 정보가 표시되면 Rust 설치가 성공적으로 완료된 것입니다! 이 정보가 표시되지 않으면 %PATH%다음과 같이 시스템 환경 변수에 Rust가 추가되어 있는지 확인하십시오.

Windows 명령 프롬프트에서 다음을 사용하십시오.

> echo %PATH%
PowerShell에서는 다음을 사용하십시오.

> echo $env:Path
Linux 및 macOS에서는 다음을 사용하십시오.

$ echo $PATH
위의 내용이 모두 정확한데도 Rust가 여전히 작동하지 않는다면 도움을 받을 수 있는 곳이 여러 군데 있습니다. 커뮤니티 페이지 에서 다른 Rust 사용자들(저희가 스스로를 부르는 재미있는 별명입니다)과 연락하는 방법을 알아보세요 .

업데이트 및 제거
Rust를 설치한 후에는 rustup새로 출시된 버전으로 쉽게 업데이트할 수 있습니다. 셸에서 다음 업데이트 스크립트를 실행하세요.

$ rustup update
Rust를 제거하려면 rustup셸에서 다음 제거 스크립트를 실행하십시오.

$ rustup self uninstall

텍스트 편집기 및 IDE 사용
이 책은 독자가 Rust 코드를 작성하는 데 어떤 도구를 사용하는지에 대한 가정을 하지 않습니다. 거의 모든 텍스트 편집기를 사용해도 충분합니다! 하지만 많은 텍스트 편집기와 통합 개발 환경(IDE)은 Rust를 기본적으로 지원합니다. Rust 웹사이트의 도구 페이지 에서 다양한 편집기와 IDE의 최신 목록을 확인할 수 있습니다.

이 책을 오프라인에서 활용하기
몇 가지 예제에서는 표준 라이브러리 외의 Rust 패키지를 사용합니다. 이러한 예제를 따라 하려면 인터넷 연결이 필요하거나 필요한 패키지를 미리 다운로드해야 합니다. 필요한 패키지를 미리 다운로드하려면 다음 명령어를 실행하세요. ( cargo각 명령어가 무엇을 하는지, 어떤 역할을 하는지는 나중에 자세히 설명하겠습니다.)

$ cargo new get-dependencies
$ cd get-dependencies
$ cargo add rand@0.8.5 trpl@0.2.0
이 명령을 실행하면 해당 패키지의 다운로드 파일이 캐시되므로 나중에 다시 다운로드할 필요가 없습니다. 이 명령을 실행한 후에는 해당 get-dependencies폴더를 유지할 필요가 없습니다. 이 명령을 실행했다면, 이 책의 나머지 부분에 --offline나오는 모든 cargo명령에서 플래그를 사용하여 네트워크를 통해 다운로드하는 대신 캐시된 버전을 사용할 수 있습니다.
