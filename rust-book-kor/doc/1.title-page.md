러스트 프로그래밍 언어
Steve Klabnik, Carol Nichols, Chris Krycho가 Rust 커뮤니티의 도움을 받아 작성했습니다.

이 문서에서는 모든 프로젝트의 Cargo.tomledition = "2024" 파일 에서 Rust 2024 에디션 관용구를 사용하도록 구성하고 Rust 1.85.0(2025년 2월 17일 출시) 이상 버전을 사용한다고 가정합니다. Rust 설치 또는 업데이트에 대한 지침은 1장의 "설치" 섹션을 참조하고 , 에디션 정보는 부록 E를 참조하십시오.

HTML 형식은 https://doc.rust-lang.org/stable/book/ 에서 온라인으로 이용할 수 있으며 , Rust 설치 시 오프라인에서도 사용할 수 있습니다 rustup. ; 실행하여 rustup doc --book열어보세요.

커뮤니티에서 제공하는 다양한 번역본 도 이용하실 수 있습니다.
